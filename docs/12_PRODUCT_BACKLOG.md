# 1. Objectif

Le Product Backlog est la liste officielle des évolutions possibles de SikaGlé.

Il centralise toutes les idées, besoins utilisateurs, améliorations techniques et nouvelles fonctionnalités qui pourront être développées après la V1.

Contrairement au Plan de Développement, ce document n'impose aucun calendrier.

Il constitue une réserve d'opportunités qui sera réévaluée à chaque nouvelle version.

---

# 2. Principes

Une fonctionnalité entre dans le backlog lorsqu'elle :

- répond à un besoin utilisateur ;
- améliore l'expérience ;
- renforce l'intelligence de SikaGlé ;
- crée une valeur métier ;
- prépare l'avenir du produit.

La présence d'une fonctionnalité dans ce backlog ne garantit pas son développement.

---

# 3. Priorités

Chaque élément reçoit une priorité.

★★★★★ Critique

★★★★☆ Haute

★★☆☆☆ Faible

Les priorités évolueront avec les retours du terrain.

- Temps de développement

# Conclusion

Le Product Backlog est le registre officiel des opportunités d'évolution de SikaGlé.

Il permet de conserver une vision à long terme tout en laissant la liberté d'adapter les priorités selon les retours des utilisateurs, les avancées technologiques et les besoins du secteur agricole.

Chaque nouvelle version du produit sera construite à partir de ce backlog, garantissant une évolution cohérente avec la vision de SikaGlé.
